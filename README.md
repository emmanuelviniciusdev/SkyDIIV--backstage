SkyDIIV is a wardrobe management app that uses AI to generate outfit combinations based on what you already own, and gives you a recurring diagnosis of your wardrobe (what's missing / what's too much / and what's just sitting there). This repo contains some of the backend services that make it all work. Feel free to poke around :vvvv
