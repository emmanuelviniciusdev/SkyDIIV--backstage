SkyDIIV is a wardrobe management app that uses AI to generate outfit combinations based on what you already own, and gives you weekly looks, a recurring panorama of your wardrobe (what's missing / what's too much / what's just sitting there), automatic thrifting for the gaps, and a creative board to collage looks yourself. This repo contains some of the backend services that make it all work. Feel free to poke around :v
